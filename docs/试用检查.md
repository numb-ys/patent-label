# 0.4.0 试用检查

安装更新后保存工作并重启 CAD。实际鼠标操作由你检查，开发检查使用独立图纸的 CAD Core Console。

1. 输入 BH，点零件位置，再点编号位置，应立即显示默认 1。
2. 不按空格，直接点下一个零件位置及编号位置，应生成 2；继续两点一组，应依次生成 3、4……。
3. 第二次点击后输入 123 或 A01，按一次空格，再直接点下一处。下一编号应为 124 或 A02。
4. 第二次点击后直接 Esc，应保留刚放好的默认编号。只点第一下就 Esc，应取消这条未完成引线，前面的标号保留。
5. 第二次点击后直接按空格，可接受默认编号；再按空格仍应等待下一处指向点，不退出。
6. 退出后 U 应逐条撤销；要重做时，U 后立即执行 REDO。
7. 输入非法字符、超过 32 个字符或会遮挡指向点的过长编号，应重新提示，原建议编号保持可用。
8. 退出 BH 后，单击数字选中标号，拖动编号中心蓝色夹点，整条线实时跟随，零件端固定；Esc 取消移动。
9. BHXG 和双击 CAD 自带属性窗口可修改已有编号，间隙同步调整；复制件独立。保存重开后检查图元完整。

中文新标号默认黑体常规，英文为 Arial 常规。BHSZ 调整字高、水平段、间隙、BHXG 改号确认键和字重。连续 BH 固定支持空格或回车确认。新旧完整标号均可继续编辑。
