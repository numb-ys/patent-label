# 0.2.4 试用检查

更新后重新启动 CAD，看到“专利附图标号 0.2.4 已加载”再试用。旧 DLL 无法在当前进程中卸载，仅重新 APPLOAD 不能停用旧版双击处理。

本次已移除自制原位输入框和双击拦截。实际交互由你检查；开发检查使用隔离图纸的 CAD Core Console，全程没有操作桌面或工作图纸。

1. **首条默认 1**：在新开图纸输入 `BH`，点击指向点与编号中心。不输入数字，直接按空格，应生成编号 `1` 并结束命令。再按一次空格才进入下一条，默认编号为 `2`，也可直接确认。
2. **预览保留**：点完第一下后，整条折线和建议编号随鼠标移动；点完第二下，输入编号期间仍显示预览。确认后保留正式标号，Esc 取消时不留半条标号。
3. **黑体常规字重**：新建编号默认使用黑体，不附加加粗。旧标号不自动变字体。`BHSZ` 可设置之后新建标号的字重；`BHJC` 可把选中的旧标号改为黑体，并选 `Regular` 或 `Bold`。
4. **命令行改号**：输入 `BHXG`，点选已有标号，在命令行输入新编号并确认。编号可用 `123`、`A`、`A01`。改号后引线间隙同步调整，复制件独立修改，Esc 保留原编号，`U` 可撤销。
5. **恢复原来的双击方式**：双击编号使用 CAD 自带的属性编辑窗口，修改后确认关闭；不再出现插件的小输入框。CAD 原生属性编辑只改文字，引线长度需要同步调整时使用 `BHXG`。

输入提示的 32 是最多 32 个字符，三位数和更大的数字均可输入。如果仍出现退出，请记录当时操作及加载版本，保留 CAD 报错信息。
