# PatentLabel 专利附图标号

[English](../README.md) | 简体中文

用于 AutoCAD 专利附图的两点标号工具：点引线指向点，点编号中心，再输入或接受建议编号。整条折线随鼠标预览；首条默认 1，可以直接确认。

## 下载与安装

从 [Releases](https://github.com/numb-ys/patent-label/releases) 下载对应 CAD 年份、语言的安装包，完整解压。打开对应 CAD 的图纸，运行安装脚本，再重启 CAD，输入 `BH` 使用。

安装一次后，该用户和 CAD 配置下随启动及新图纸自动加载，无需每张图纸重新 APPLOAD。英文包运行 `Install.cmd`；中文包按包内“先看这里”教程运行对应年份的脚本。

## 基本操作

1. 输入 `BH`，回车。
2. 点击要标记的零件位置。
3. 移动鼠标预览整条折线，点击编号中心。
4. 首条默认 `1`，可直接空格或回车确认，也可先输入其它编号。本条确认后命令结束。
5. 再按一次空格，由 CAD 重复 `BH`，开始下一条并建议递增编号。

支持 `123`、`A`、`A01` 等 1-32 个数字或英文字母。`BHXG` 在命令行改号并更新引线；`BHSZ` 调整字高、水平段、间隙、确认键和字重；`BHJC` 修改所选标号字体与字重。英文包可用 `BHVER` 查看模块状态。

中文新标号默认黑体常规，英文新标号默认 Arial 常规。双击使用 CAD 自带的属性窗口；插件原位编辑已移除。复制件可以独立改号。

## 版本与验证

提供 Windows 完整版 AutoCAD 2014、2019、2026 的独立包。2014/2019 已按对应接口编译，需要在这些 CAD 中实机试用；2026 的 Core Console 自动检查不等于所有桌面交互都已验证。英文 Windows 和英文 CAD 也需要试用确认。暂不支持 LT、macOS、中望、浩辰或其它未列出的版本。

同一 CAD 年份仅使用一种语言。运行目标语言的安装脚本可以切换该年份的插件，随后必须重启 CAD；不要在同一进程手动 NETLOAD 两种语言。
