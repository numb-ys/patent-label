# Security reports

For a vulnerability involving credentials, arbitrary file writes or code execution, use GitHub's private vulnerability reporting feature if it is available. Otherwise contact the maintainer through the GitHub profile and request a private reporting route before sending details. Do not post tokens or confidential drawings in a public issue.

The plug-in runs code inside AutoCAD. Download releases from this repository, review the source when needed, and use a supported AutoCAD installation. Installers add only their exact owned plug-in directory to trusted locations and do not lower `SECURELOAD`.

This is a preview project. There is no committed response-time or support SLA.
